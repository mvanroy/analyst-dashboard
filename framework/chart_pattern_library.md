# Chart Pattern Library

> Pattern-specific field guide for [Trade Setup Framework](trade_setup_framework.md) Phase 3. The chart always takes precedence over this reference. Purpose: answer "Could this become the pattern with tradable upside?" — not "Has the pattern already completed?"
>
> Each entry follows: **Description → evidence table (Location / Behaviour / Structural Development, in sequence of occurrence) → Confluence → Failure Lens → Entry Mode Logic.**

## CONTINUATION PATTERNS

### Bull Flag

A continuation pattern in which a strong bullish impulse pauses through controlled profit-taking rather than a transfer of control to sellers.

| Section | Observation | Possible Interpretation |
|---|---|---|
| **Location** | Prior breakout level | Buyers often defend newly established support |
| | AVWAP support | Trend participants defend average entry price |
| | EMA support | Dynamic support attracts trend buyers |
| | HTF support | Higher timeframe demand reinforces continuation |
| | Prior resistance becoming support | Acceptance above former resistance supports the bullish thesis |
| | Liquidity above prior highs | Upside objectives remain available |
| **Behaviour** | Controlled pullback | Profit-taking rather than trend reversal |
| | Reduced downside momentum | Sellers becoming less effective |
| | Compression | Energy building for expansion |
| | Selling exhaustion | Supply diminishing |
| | Buyer response at support | Demand remains active |
| | Failed breakdown | Trapped sellers strengthen continuation |
| | Higher lows inside consolidation | Buyers defend increasingly higher prices |
| **Structure** | Strong bullish impulse established | Pattern foundation exists |
| | Pullback begins | Profit-taking phase develops |
| | Pullback remains contained | Control remains with buyers |
| | Flag boundaries become visible | Consolidation becomes recognisable |
| | Volatility contracts | Market transitions from expansion to compression |

**Confluence:** Trend aligned with HTF structure; rising AVWAP/EMA support; declining pullback volume (profit-taking exhausting); rising open interest during expansion; positive CVD / buyer aggression; increasing volume on breakout; strong trend slope; liquidity resting above highs (upside objectives).

**Failure Lens:** Pullback becomes impulsive (distribution risk); AVWAP support lost; prior breakout level lost; support becomes resistance; volatility expands downward; lower highs and lower lows develop; breakdown from consolidation with follow-through (thesis invalidated).

| Entry Mode | Typical Conditions |
|---|---|
| **Aggressive** | Strong impulse established. Pullback approaching support. Selling pressure weakening. Risk clearly defined. |
| **Balanced** | Flag structure visible. Compression developing. Buyers responding to support. Trigger level identifiable. |
| **Chasing** | Breakout underway. Buyers regained initiative. Momentum expanding. R:R deteriorating. |

### Symmetrical Triangle

A compression pattern in which buyers and sellers progressively agree on value through converging highs and lows. Volatility contracts and directional conviction temporarily diminishes, creating stored energy that can eventually resolve in either direction.

| Section | Observation | Possible Interpretation |
|---|---|---|
| **Location** | Existing trend or range | Pattern often develops as a pause within a broader structure |
| | HTF / AVWAP support or resistance | Higher-timeframe levels and trend participants influence resolution |
| | Prior breakout/breakdown level | Existing structure provides context |
| | Converging trendlines | Compression becomes visible |
| | Liquidity resting beyond both boundaries | Expansion objectives remain available |
| **Behaviour** | Higher lows and lower highs | Buyers and sellers reaching temporary equilibrium |
| | Compression / volatility contraction | Energy building; participation narrows |
| | Reduced expansion in both directions | Conviction temporarily diminishes |
| | Failed breakouts/breakdowns within the structure | Neither side can sustain control |
| | Repeated reactions from both boundaries | Compression becomes increasingly efficient |
| | Momentum coiling | Expansion pressure increases |
| **Structure** | Prior trend or range established | Pattern foundation exists |
| | Upper boundary falls / lower boundary rises | Resistance and support lines develop |
| | Boundaries converge; volatility contracts | Triangle becomes recognisable |
| | Multiple reactions reinforce both boundaries | Compression strengthens |
| | Apex approaches; trigger identifiable | Expansion pressure increases |
| | One boundary breaks with expansion | Pattern becomes Triggered |

**Confluence:** Compression visible across multiple timeframes; rising OI during expansion; increasing volume on breakout/breakdown; positive or negative CVD (reveals dominant side); BTC strength or weakness; HTF support/resistance nearby; neutral-to-favourable funding; liquidity beyond the boundaries.

**Failure Lens:** Compression disappears; one boundary repeatedly fails to attract response; volatility expands without follow-through; false breakout repeatedly returns inside structure; AVWAP support/resistance loses relevance; boundaries become irregular; sustained acceptance inside a deteriorating structure (thesis invalidated).

| Entry Mode | Typical Conditions |
|---|---|
| **Aggressive** | Compression visible. Boundaries converging. Risk clearly defined. Directional resolution not yet obvious. |
| **Balanced** | Triangle structure visible. Volatility contracting. Apex approaching. Trigger level identifiable. |
| **Chasing** | Breakout or breakdown underway. One side regained initiative. Momentum expanding. R:R deteriorating. |
